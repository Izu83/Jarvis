Siri & Share

You make this once, in the iPhone's Shortcuts app. Then say “Hey Siri, Ask Jarvis”, or pick Ask Jarvis under any app's Share button. Siri reads the answer out.

  1. In Shortcuts, tap + and name the shortcut Ask Jarvis.
  2. Open its details (ⓘ) and turn on Show in Share Sheet. At the top, let it receive Text and URLs, and set If there's no input to Ask For › Text.
  3. Add URL Encode (it uses the Shortcut Input).
  4. Add Get Contents of URL and paste the address link below.
  5. Add Get URLs from Input.
  6. Add another Get Contents of URL (it uses those URLs). Tap Show More › Headers and add two:
    X-Jarvis-Key = the key below
    X-Jarvis-Ask = the URL Encoded Text from step 3
  7. Add Show Result.
