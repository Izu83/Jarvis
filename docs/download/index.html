Jarvis for Windows

Put Jarvis on another computer. One installer does everything.

Download

jarvis-setup.exe · Windows 10 and 11

The installer runs on a Windows computer. Open this page there, or send it the link.

Open Jarvis

After it downloads

  1. Open jarvis-setup.exeIt's in your Downloads folder.
  2. If Windows protects your PCThe installer isn't signed, so Windows may warn you. Choose More info › Run anyway.
  3. Choose a folder and click InstallIt suggests a drive with room. Each step shows its progress; most installs take 10 to 20 minutes.
  4. Log in to ClaudeA window opens once. Jarvis then starts by itself and shows a QR code.
  5. Connect your iPhoneIn Jarvis, open Settings › Your computers › Add a Computer and scan the QR code.

What it installs

  • GitTo download and update Jarvis
  • Python 3.13With the Visual C++ runtime
  • Node.jsFor the hidden browser
  • Google ChromeFor website jobs
  • Claude CodeJarvis's brain
  • cloudflaredSo your phone can reach him
  • Python packagesVoice, camera and the rest
  • JarvisStarted for you at the end

Anything already there is skipped. Run it again any time to update Jarvis.
